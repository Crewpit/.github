# Crewpit
 
**Unofficial add-on apps for the Cockpit web console: small, independent tools for running Linux servers.**
 
Each app lives in its own repository, with its own code, issues and releases. What they share is the theme: they all plug into [Cockpit](https://cockpit-project.org/).

Treat everything as experimental and not ready for production..

Vibe-coded app submissions are allowed as long as you test them and add info about the validadtion environment (OS version, cockpit version, any dependencies and their version, etc)
