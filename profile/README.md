# Crewpit
 
**Unofficial add-on apps for the Cockpit web console: small, independent tools for running Linux servers.**
 
Each app lives in its own repository, with its own code, issues and releases. What they share is that they all plug into [Cockpit](https://cockpit-project.org/).

*This project started as an experiment of porting and improving features from other projects such as Dashy, OpenWRT, OPNSense, Webmin, Portainer and others. There is no specific end-goal in sight.*

"Apps" will be published for specific usecases and they can be mixed and matched to tailor whatever you are building on a full Linux distro. As such, the recommended way of installing Cockpit apps is using **[Crewmate](https://github.com/Crewpit/crewmate)** which will check for dependencies and proper versioning as well as allow you to upgrade packages without manual CLI interaction :)

Treat everything as experimental and not ready for production..

\* Vibe-coded app submissions are allowed as long as you test them and add info about the validadtion environment (OS version, cockpit version, any dependencies and their version, etc)
